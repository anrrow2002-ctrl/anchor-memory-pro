# Anchor Memory · 跑团记忆整理版

版本 **1.1.4-rp.3**。

在酒馆「扩展」中使用本仓库地址安装；已有安装点击更新，再刷新酒馆页面。插件关闭自动更新，已打开的页面需要刷新后才会加载新代码。

本版修复：

- 「锚点记录」固定注入在聊天记录之后，保留末尾其他指令的顺序。旧注入深度设置自动迁移为 0，聊天压缩后不足四条消息时也不会退回第一条 system 前。记忆正文和摘要提示词保持原样。
- 当前楼生成或推理时间超过 30 秒仍持续等待，不把超时当作完成；正文完成或停止后再整理。已提交消息加上酒馆明确空闲状态也能恢复漏发的结束事件。
- 当前楼仍在生成、等待稳定时，不弹「没有生成逐楼摘要」警告；同一失败的提示去重不再受正文指纹变化影响。旧历史的真实失败仍会提示。

运行检查：`npm test`（Node.js >= 18）。检查覆盖短/长聊天、注入前缀稳定、工具调用、旧设置迁移、慢速生成、停止/完成、缺失结束事件和警告去重。

实际缓存命中还取决于模型服务商、缓存有效期及其他提示词变化；本版保证插件更新的记忆块不再插入聊天历史前部。
